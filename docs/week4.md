# Homework

### Advanced 3D Game Design Prototype 4: Input & Particle Exploration

#### Input Actions
Create a small prototype which captures  player input using the "new" Input System (Unity) or Input Actions (UE5). You may use the default inputs for things like movement, but please create at least one custom input action of your choice. Additionally, the input actions need to be controllable with both keyboard/mouse and a gamepad.

#### Particle System
Create a minimum of 2 different particle systems. At least one of these should consist of multiple layered subsystems (Unity) or Niagara Emitters (UE5) and the other should be triggered as the result of an interaction (input action, collision, etc.).

This exploration can be a continuation of any previous week's homework, a new, self-contained prototype, focused on highlighting the materials, or something else you’ve already made that you incorporate your implemented shaders into.

Keep it small but interesting.

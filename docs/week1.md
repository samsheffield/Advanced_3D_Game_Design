# Homework

### Set up workspace
- Install Unity 6 and/or Unreal Engine 5.5. These will be used for demos this semester.
- Clear space on your hard drives. Time to back up your work in preparation for the semester ahead.
- Create a working folder in our course folder on the Picasso server named *Lastname_Firstname_GMD340*.

### Semester warm-up
As a warm-up for this semester, create a small prototype using the engine of your choice. Please spend no more than 5 hours developing the prototype this week. There are two goals for this assignment:
1. To familiarize you with the open-ended expectations for weekly work in this class.
2. To reacquaint you with the tools we'll be using this semester.

#### Basic Requirements
- Prototype must be in 3D.
- It doesn't need to be complicated but it does need to interest you.
- It should include some basic goal which takes you from one level/scene to another.
- It does not need to be polished.
- Upload project files to a *Lastname_Firstname_Warmup* folder in our Picasso course folder.
- Be prepared to show it to others next week at the start of class.

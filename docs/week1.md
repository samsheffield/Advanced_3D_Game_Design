## Homework

### Option #1: #### Warm-up
When was the last time you used Unity or Unreal? Let’s get warmed up by creating a *very* small prototype using either engine. There are technical requirements listed below, but the thematic details, goals, mechanics, etc. are up to you. *Please do not continue work that was started in a previous semester for this assignment.*

__Here are the technical requirements:__
- Built using Unity or Unreal
- At least 2 scenes or levels
- Basic UI (this may just be a title)
- Basic collision or trigger/overlap interaction
- Use of sound (background audio or triggered samples)
- At least one imported FBX (created by you or from another source. Static or Skeletal Meshes are both okay!)
- At least one material created using the Material Editor (UE5) or Shader Graph (Unity)

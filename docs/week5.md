### Advanced 3D Game Design Prototype 5: Behavior Exploration

Create a small prototype which controls a non-playable agent using in Unity or UE5. If you're feeling stuck, you can focus on recreating the different movement behaviors from the demo, but please alter it so that there is at least one different or new thing.

This exploration can be a continuation of any previous week's homework, a new, self-contained prototype, focused on highlighting the behaviors, or something else you’ve already made that you incorporate your implemented shaders into.

Keep it small but interesting.
